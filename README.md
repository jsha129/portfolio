- **Melbourne Property Market Analysis**: To estimate annual growth rate of properties by suburbs of Melbourne (Australia) using publicly available data and visualise the results on a map (https://github.com/jsha129/PropertyPy).
    + **Methods:** API requests, json data, geopandas, linear regression, integration of data from multiple sources.  
    + **Language(s):** Python
- **Stock Market Forecasting**: To identify ASX companies with high growth potential from fundamental data (in progress, unpublished).
  + **Methods:** (1) Historic stock prices and fundamental data (balance sheet, cashflow statement and income statement) were retrieved using unix, api requests and stored in an SQLite database, (2) Linear regression was used to estimate compounded annual growth return (CAGR), (3) Companies were categorised into two groups based on CAGR followed by logistic regression and feature selection methods were used to identify important fundamental ratios predictive of companies with potential high growth, and (4) Principal component analysis (PCA) was used for visulisation and correlation between features. 
  + **Language(s):** Python, R, unix, SQL

    + **Language(s):** R
- **<a name="spotifyr"></a>Finding new music on Spotify**: An automated programme to find unique top 40 songs each month by text-mining multiple Billboard charts and adding them to a user's Spotify account (https://github.com/jsha129/SpotifyR).

    + **Language(s):** R
